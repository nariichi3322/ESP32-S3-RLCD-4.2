# WeatherClock クイックスタート

## 初期設定

1. 電源を入れ、本体に表示された WeatherClock のアクセスポイントへ接続します。パスワードは本体表示を確認してください。
2. 自動で設定画面が開かない場合、`http://192.168.4.1/` を開きます。「インターネットなし」と表示されても接続を維持します。
3. Wi-Fi名とパスワードを入力します。予備のWi-Fiと天気の都市は省略できます。
4. 保存して検証を待ちます。失敗時は項目を修正し、成功すれば通常画面へ移ります。

このフォークではQWeatherは非推奨で使用しません。天気はOpen-Meteoのみで、API KeyもAPI Hostも不要です（下の「天気（Open-Meteo）」を参照）。オフラインで使う場合はWi-Fiを空欄にし、日付と時刻を入力してください。オンライン設定ではオフライン用日時は空欄で構いません。

## ボタン

- **BOOTを短く押す**：次の画面へ。設定では決定。
- **KEYを短く押す**：設定を開く。設定では項目を移動。
- **KEYを長押し**：前の階層に戻る、または設定を終了。
- **通知音が鳴っているとき**：どちらのボタンでもアラーム・集中終了音を止められます。

設定画面は約30秒無操作で終了します。本体のUIは主に簡体字中国語です。日本語の説明書があっても、UIの言語切り替えを提供するわけではありません。

## 普段の使い方

天気時計、画像時計、天気ダッシュボード、温湿度時計、カレンダー、履歴、Xiaozhi AI、統合時計の8画面があります。表示設定で有効化と順序を変えられます。先頭がホームで、AI以外の画面を最低1つ残します。

天気は必要に応じて毎正時に同期します。内蔵画像は曜日に合わせて毎日切り替わり、アップロード画像は周期を選べます。センサーは昼間に約1分、夜間に約2分間隔です。AIは電力を多く使い、基板の発熱が温度表示に影響する場合があります。

音声ツールで単発アラーム、集中タイマー、天気の都市を設定できます。画面の結果も確認してください。通常の「何分後に知らせて」はアラームです。集中したい場合は集中タイマーを明示します。既存アラームの上書きには確認が必要です。

## 更新と困ったとき

- システム設定でBOOTを押して更新確認し、見つかったら60秒以内に確認します。
- PCでは [WeatherClock Studio](https://nariichi3322.github.io/ESP32-S3-RLCD-4.2/) で素材作成、プレビュー、書き込み、ログ表示ができます。
- Web UIは狭い画面で閲覧でき、シミュレーターは上下配置になります。素材書き込み、ファームウェア書き込み、シリアル操作にはWeb Serial対応のPC版ChromeまたはEdgeが必要です。
- ファームウェア画面の既定は「オンライン完全インストール」です。初回導入やパーティション移行では、デバイスを接続してチップとFlash容量を確認してから、ファームウェア・パーティション・素材の上書きを確認してください。設定や自作素材を残す場合は「高度なファームウェア書き込み」でApp更新を使います。スマートフォンは閲覧のみで、シリアル書き込みはできません。
- 右上で日本語・英語・簡体字中国語・繁体字中国語（台湾）を選択でき、選択はブラウザーに保存されます。ファームウェア画面やWi-Fi設定デモ内部の言語は変わりません。
- 天気が更新されない場合は通信状態と天気の都市を確認します。古い値の表示は更新成功を意味しません。
- Wi-Fiアイコンは無線動作を示します。電池と充電表示は推定で、USB接続と充電継続は同じではありません。
- オフラインではローカル画面だけを使います。オンライン復帰には完全な設定が必要です。
- **App binを0x0に書き込まないでください。OTAではパーティションテーブルを更新できません。**
- 工場出荷時設定へのリセットでもAIの紐付け、履歴、自作素材は残ります。全フラッシュ消去とは異なります。

認証情報や私用アドレスを含むログ・設定リンクを公開しないでください。初回書き込みや詳しい対処は[詳細ガイド](User_Detailed_ja.md)へ。
現在のファームウェアはUTC+8固定で、日本標準時（UTC+9）とは1時間異なります。タイムゾーンを変更する設定はありません。

## 天気（Open-Meteo）

天気はOpen-Meteoのみを使い、API KeyもAPI Hostも不要です。このフォークではQWeatherは非推奨で、使用しません。

設定で天気の都市は省略できます。空の場合はIPジオロケーション（ipwho.is）で位置を判定し、Wi-Fiネットワークごとに最大6時間キャッシュします。手動で入力した都市はOpen-Meteoのジオコーディングで解決し、24時間キャッシュします。

表示内容は、現在の天気、日の出・日の入りを含む6日間の予報、次の5時間分の時間別予報、そしてUS AQIの大気質と主な汚染物質です（中国のAQIではありません）。気象警報は提供しません。公開APIは非商用なら無料で、通信状態にも左右されます。オフラインでは引き続き日時だけを設定します。

天気データ：[Open-Meteo.com](https://open-meteo.com/)（CC BY 4.0）。大気質には[CAMS](https://atmosphere.copernicus.eu/)のデータを含みます。都市検索：[GeoNames](https://www.geonames.org/)。
