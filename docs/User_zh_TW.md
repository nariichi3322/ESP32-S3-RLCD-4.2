# WeatherClock 快速入門

[詳細說明](User_Detailed_zh_TW.md) · [简体中文](User_zh.md) · [English](User.md) · [日本語](User_ja.md)

## 先完成網路設定

1. 開機後連上螢幕顯示的 WeatherClock 熱點，密碼以裝置畫面為準。
2. 開啟自動出現的設定網頁；若沒有出現，輸入 `http://192.168.4.1/`。手機提示無網際網路時，請維持連線。
3. 填入主要 Wi-Fi 與密碼。備用網路和天氣城市可留白。
4. 儲存後等待驗證；失敗時依提示修正，成功後會自動進入一般畫面。

本分支已棄用和風天氣（QWeather），不再使用；韌體只使用 Open-Meteo，不需要 API Key 或 API Host（見下方「天氣（Open-Meteo）」）。只想離線使用時，Wi-Fi 留白並填日期時間即可；線上使用則可將離線日期時間留白。

## 按鍵操作

- **短按 BOOT**：切換畫面；在設定中確認。
- **短按 KEY**：開啟設定；在設定中移動游標。
- **長按 KEY**：返回上一層或離開設定。
- **提醒音效播放中按任一鍵**：停止鬧鐘或番茄鐘音效。

設定頁約 30 秒沒操作會自動退出。本體選項目前主要是簡體中文，本文件為繁體使用說明，並非介面語言切換功能。

## 日常使用

共有天氣時鐘、圖片時鐘、天氣看板、溫溼時鐘、月曆、溫溼歷史、小智 AI、整合時鐘八頁。顯示設定可以開關頁面及排序；第一項是首頁，至少須保留一個非小智頁面。

天氣依整點需求更新；內建圖片每天依星期切換，自訂圖庫可調週期。本機溫溼度在白天約每分鐘、夜間約每兩分鐘取樣。小智較耗電，板子升溫可能影響溫度數值。

小智可設定單次鬧鐘、番茄鐘與天氣城市，請確認畫面上的結果。一般延後提醒是鬧鐘，專注計時請明確說「番茄鐘」。覆蓋既有鬧鐘前須確認。

## 更新與排除問題

- 系統設定中以 BOOT 檢查更新，找到新版後在 60 秒內確認下載。
- 電腦可使用 [WeatherClock Studio](https://nariichi3322.github.io/ESP32-S3-RLCD-4.2/) 製作素材、預覽、燒錄與查看記錄。
- 網頁支援窄螢幕瀏覽，模擬器會自動改為上下排列；素材寫入、韌體燒錄與序列埠功能仍需支援 Web Serial 的電腦版 Chrome 或 Edge。
- 韌體頁預設提供「線上完整安裝」。首次安裝或分割區遷移前，請先連線並確認晶片與 Flash 容量，再確認覆蓋韌體、分割表與素材。若要保留裝置設定或自訂素材，請取消並使用下方進階 App 更新；手機僅能瀏覽，不能進行序列埠安裝。
- 網頁右上角可切換繁體中文、簡體中文、日文或英文，瀏覽器會記住選擇；不會改變韌體畫面或連網設定模擬器內的語言。
- 天氣不更新時，先檢查網路連線與天氣城市；快取資料不代表本次同步成功。
- Wi-Fi 圖示是無線電狀態；電池與充電圖示皆為估算，USB 插著不表示持續充電。
- 離線時只啟用本地頁面，要恢復連網須有完整設定。
- **App bin 不可燒到0x0，OTA也不能改分割表。** 首次燒錄或舊版升級請先讀詳細說明。
- 恢復原廠設定保留小智綁定、歷史與自訂素材，不等於清除整片 Flash。

不要公開含帳密或私人位址的記錄及設定連結。更多操作請參閱[詳細說明](User_Detailed_zh_TW.md)。
目前韌體固定使用 UTC+8，尚無時區選項；翻譯文件不會改變裝置時區。

## 線上與離線模式

設定模式提供兩條獨立路徑。線上使用時，填寫主要 Wi-Fi，並可選填備用 Wi-Fi、NTP 伺服器與天氣城市。線上設定儲存成功後會退出離線模式，並排程時間、天氣與每日一言同步。

離線使用時，填寫目前的本地日期時間。裝置會持久化離線模式、關閉 Wi-Fi、阻擋背景網路工作，並隱藏需要網路的頁面。若裝置已保存有效 Wi-Fi，可直接關閉離線模式；否則會進入設定模式。

## 天氣（Open-Meteo）

天氣資料只來自 Open-Meteo，不需要 API Key 或 API Host。本分支已棄用和風天氣（QWeather），不再使用，也沒有天氣來源切換開關。

設定時天氣城市可留白；留白時裝置以公開 IP 定位（ipwho.is）取得座標，每個 Wi-Fi 網路最多快取 6 小時，並直接使用座標查詢 Open-Meteo。手動填寫的城市會以 Open-Meteo Geocoding API 解析，並快取 24 小時。

顯示內容：目前天氣、六日預報（含日出日落）、接下來 5 筆逐時預報，以及 US AQI 空氣品質與主要污染物。此整合不提供天氣警報。天氣狀態依 WMO interpretation code 顯示供應商中立的單色圖示。公共介面僅供非商業使用，仍須確認網路可連線。

天氣資料由 [Open-Meteo.com](https://open-meteo.com/) 提供（CC BY 4.0）。資料來源：[Open-Meteo Forecast API](https://open-meteo.com/en/docs) 與 [Geocoding API](https://open-meteo.com/en/docs/geocoding-api)。空氣品質包含透過 [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) 提供的 CAMS 衍生資料。重新散布韌體或含天氣資訊的畫面時，請保留上述 attribution。

## CODEX Usage 藍牙

CODEX 頁由通用頁面顯示／順序設定管理。正常顯示 CODEX 頁時會啟動藍牙；從 CODEX 開啟「設定」overlay 時，藍牙傳輸與配對狀態會持續保留。離開 CODEX 到一般工作頁時會進入寬限停止：藍牙及其配對／連線狀態最多保留 60 秒，期間回到 CODEX 會取消停止。只要傳輸仍在運作，工作頁上方的藍牙狀態圖示會持續依目前連線狀態顯示；期限到達、傳輸停止後圖示才消失。低電量、OTA Checking 或 Updating、配網入口網站已排入請求或已啟動，以及非「設定」輔助頁，則會立即停止藍牙。

需要改與其他客戶端配對時，使用「系統 > 清除 CODEX 配對」。

## 系統選單

系統選單固定包含：離線模式、恢復出廠、關於本機、清除 CODEX 配對、語言、設定模式、OTA、網路檢測。網路檢測會檢查 Open-Meteo 公開端點，以及 Wi-Fi、DNS、NTP、每日一言、公網和 OTA 來源。

## 升級

此版本第一次啟動時，會冪等刪除舊天氣憑據與舊 CODEX 獨立功能開關的 NVS 值。Wi-Fi、天氣城市、頁面顯示／順序、語言、鬧鐘及其他設定都會保留，不需要恢復出廠。
