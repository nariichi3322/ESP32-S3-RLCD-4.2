# WeatherClock 简易用户手册

[详细说明](User_Detailed_zh.md) · [繁體中文](User_zh_TW.md) · [日本語](User_ja.md) · [English](User.md)

## 先完成配网

1. 开机后连接屏幕显示的 `WeatherClock-` 热点，密码以屏幕为准。
2. 打开自动弹出的网页；没有弹出就访问 `http://192.168.4.1/`。手机提示无互联网时选择保持连接。
3. 填写主 Wi-Fi 和密码。备用 Wi-Fi 和天气城市可留空，无需填写天气 API Key。
4. 点击保存并等待验证；失败按提示修改，成功后设备自动进入工作页。

只想离线使用时，Wi-Fi 留空，填写日期时间即可。联网使用时离线日期时间可留空。

## 两个按键

- **BOOT 短按**：切换工作页；在设置里确认。
- **KEY 短按**：进入设置；在设置里移动选择。
- **KEY 长按**：返回上一级，或退出设置。
- **提示音播放时按任意键**：先停止闹钟/番茄钟提示音。

设置里约 30 秒不操作会自动退出。

## 日常使用

八个页面分别是天气时钟、图片时钟、天气看板、温湿时钟、日历、温湿历史、小智 AI、聚合时钟。“设置 → 显示”可开关和排序，第一项是主页，至少保留一个非小智页。

天气按需整点更新。内置图片按星期每天切换；自定义图库可调整周期。本地温湿度白天约每分钟、夜间约每两分钟采样。小智耗电较高，使用时发热可能影响本地温度。

小智可以设置单次闹钟、番茄钟和天气城市。请核对屏幕结果；普通延时提醒是闹钟，“专注/番茄钟”才是专注计时。已有闹钟被替换前需要确认。

## 更新、资源与常见问题

- OTA：“设置 → 系统 → 检查更新”，按 BOOT 检查，发现更新后在 60 秒内确认。
- [WeatherClock Studio](https://nariichi3322.github.io/ESP32-S3-RLCD-4.2/)：在电脑浏览器制作素材、查看预览、写入固件和读取日志。
- 网页支持窄屏浏览，模拟器会自动改为上下布局；写入素材、烧录固件和串口功能仍需支持 Web Serial 的桌面版 Chrome 或 Edge。
- 固件页默认提供“在线完整安装”，首次安装或分区迁移应先连接设备并确认芯片与 Flash 容量，再确认覆盖固件、分区表和资源。要保留设备配置或自定义资源，请取消并使用下方高级 App 更新；手机只能浏览，不能进行串口安装。
- 网页右上角可切换简体中文、繁体中文、日本语或英语，浏览器会记住选择；不改变固件画面或配网模拟器内部语言。
- 天气不更新：先检查网络和天气城市；旧缓存不代表同步成功。
- Wi-Fi 图标表示射频开启，不保证已联网。电量与充电图标是估算，插着 USB 不一定一直充电。
- 离线模式下只能启用本地页面；重新联网需要完整配置。
- **App bin 不能刷到0x0；OTA不能更新分区表。** 首次刷机或旧分区迁移请阅读详细说明和发行说明。
- 恢复出厂会清除网络和普通设置，但保留小智绑定、历史及自定义资源；不等于全片擦除。

不要公开带有 Wi-Fi 密码或私人地址的日志、截图和快捷配置链接。更多操作和故障处理见[用户详细说明](User_Detailed_zh.md)。
当前固件固定使用 UTC+8 时区，没有时区切换选项；日文/英文手册不改变设备时区。

## 线上与离线模式

设置模式提供两条独立路径。线上使用时，填写主 Wi-Fi，并可选填备用 Wi-Fi、NTP 服务器与天气城市。线上设置保存成功后会退出离线模式，并排程时间、天气与每日一言同步。

离线使用时，填写当前的本地日期时间。设备会持久化离线模式、关闭 Wi-Fi、阻止后台网络工作，并隐藏需要网络的页面。若设备已保存有效 Wi-Fi，可直接关闭离线模式；否则会进入设置模式。

## 天气

天气数据由 Open-Meteo 提供，不需要 API Key 或自定义 Host。手动填写城市时，设备使用 Open-Meteo Geocoding API 解析；城市留空时，设备以公开 IP 获取坐标，并直接使用坐标查询 Open-Meteo。

天气看板显示当前天气、六日预报及当前空气质量。此集成不提供天气预警。天气状态依 WMO interpretation code 显示供应商中立的单色图标。

数据来源：[Open-Meteo Forecast API](https://open-meteo.com/en/docs) 与 [Geocoding API](https://open-meteo.com/en/docs/geocoding-api)。空气质量包含通过 [Open-Meteo Air Quality API](https://open-meteo.com/en/docs/air-quality-api) 提供的 CAMS 衍生数据。重新分发固件或含天气信息的画面时，请保留上述 attribution。

## CODEX Usage 蓝牙

CODEX 页由通用页面显示／顺序设置管理。正常显示 CODEX 页时会启动蓝牙；从 CODEX 打开“设置”overlay 时，蓝牙传输与配对状态会持续保留。离开 CODEX 到一般工作页时会进入宽限停止：蓝牙及其配对／连接状态最多保留 60 秒，期间回到 CODEX 会取消停止。只要传输仍在运行，工作页上方的蓝牙状态图标会持续依当前连接状态显示；期限到达、传输停止后图标才消失。低电量、OTA Checking 或 Updating、配网门户已排入请求或已启动，以及非“设置”辅助页，则会立即停止蓝牙。

需要改与其他客户端配对时，使用“系统 > 清除 CODEX 配对”。

## 系统菜单

系统菜单固定包含：离线模式、恢复出厂、关于本机、清除 CODEX 配对、语言、设置模式、OTA、网络检测。网络检测会检查 Open-Meteo 公开端点，以及 Wi-Fi、DNS、NTP、每日一言、公网和 OTA 来源。

## 升级

此版本第一次启动时，会幂等删除旧天气凭据与旧 CODEX 独立功能开关的 NVS 值。Wi-Fi、天气城市、页面显示／顺序、语言、闹钟及其他设置都会保留，不需要恢复出厂。
