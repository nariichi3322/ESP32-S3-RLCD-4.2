v100.0.3：

重要提示：升級後不再使用 QWeather API Key 與 API Host；舊欄位會自動清除，既有 Wi-Fi、城市、頁面及其他設定不受影響。由於新資料源不提供原有的天氣預警，本版本同步移除天氣預警功能。

## 新增

1. 天氣服務全面改用免 API Key 的 Open-Meteo，提供目前天氣、六日預報與空氣品質資料。
2. 天氣城市改為選填：可手動輸入全球城市，留空時則以 IP 座標自動定位。
3. 恢復可選的線上／離線模式；離線啟動可手動設定日期時間，重新儲存有效 Wi-Fi 設定後會自動回到線上模式。

## 修复

1. 修正 CODEX 頁面第二次進入後 BLE 無法再次連線的問題，並改善快速切頁、啟動失敗與重新連線時的處理。
2. 從 CODEX 頁開啟一般設定時保持 BLE 連線；僅在停用 CODEX 頁、進入配置模式、開始 OTA 更新、低電量或切離 CODEX 時關閉。
3. 簡化 IP 自動定位的城市名稱，例如「中國 台灣 新北市」現在顯示為「新北」。
4. 天氣尚未取得時不再以未知圖示表示同步進度，天氣時鐘、天氣看板與預報會改為顯示同步或等待文字。
5. 修正各頁溫度單位缺少度數圓點的問題，天氣、本機感測器、狀態列與溫度歷史統一顯示為 `°C`。
6. 系統設定改為一般與維護兩頁，每頁顯示四項；恢復可見的「檢查更新」，並避免選項超出畫面或互相覆蓋。

## 优化

1. 更新天氣圖示外觀，保留 Open-Meteo/WMO 天氣分類，並使用精簡的單色圖示素材降低韌體資源占用。
2. 強化 Open-Meteo 回應驗證與錯誤隔離；空氣品質暫時失敗時，不再覆蓋已成功取得的目前天氣與預報。
3. 精簡配網頁面的天氣設定，不再要求 API Key 或自訂 Host，並在升級時自動清理不再使用的舊設定欄位。
4. 改善電池讀值：採用五次取樣去極值平均與 18650 放電曲線，降低瞬時波動並使電量百分比更貼近實際狀態。
