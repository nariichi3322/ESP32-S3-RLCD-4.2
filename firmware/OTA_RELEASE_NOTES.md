v100.0.4：

## 重要提示

1. 舊分區先刷 v100.0.4 merged，勿直接 App-only OTA。

本版本新增 `lang` 分區並縮小 `assets` 分區，分區表與 v100.0.3 及更早版本不相容。完整刷寫前請先備份需要保留的設定與自訂資源；NVS／既有設定是否保留，取決於實際映像涵蓋範圍、刷寫命令或工具，不予保證。完成分區更新後，具備新版分區表的裝置才可使用 App-only OTA。

## 新增

1. 建立繁體中文、簡體中文、English 與日本語四種固件版本；OTA 清單會依裝置選擇的語言提供對應 App 映像。
2. 天氣看板新增每日預報與逐時預報卡片切換，方便依螢幕版面選擇所需資訊。
3. 新增聚合時鐘頁，整合時間、天氣、預報高低溫、農曆日期與本機感測器資料。

## 修復

1. 修正聚合時鐘標籤、溫度數字與度數圓點的排版，改善不同資料狀態下的可讀性。
2. 修正設定入口、頁面排列與部分頁面文字在不同語言或畫面尺寸下的顯示問題。
3. 改善 Codex 頁面 BLE 重連、快速切頁、啟動失敗與 USB 喚醒等生命週期處理，降低再次進入後無法連線的機率。

## 優化

1. 全面集中 UI 文字與字型資源，支援繁體中文、簡體中文、English 與日本語，並在建置階段檢查文字目錄完整性。
2. IP 公網定位與公網 IP 查詢改用 `ipwho.is`，並補強回應解析與失敗隔離。
3. 優化 BLE 與電源管理：非必要時釋放無線與電源鎖，改善 Codex 使用後的待機行為；正式預設仍維持穩定優先的 BLE 設定。
4. OTA 建置流程改為產生四語言 App 與完整刷寫映像，並由 Release 建置流程自動計算 SHA-256、檔案大小與更新清單。
